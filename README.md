## 2026-10-19 美圖工作室補齊互動聖經 v2.19–v2.20 的功能
- **AI 生成美圖**（相片分頁）：依這節經文自動寫好提示詞，可選畫風、尺寸、補充畫面；「在 App 內直接生成」（免費 Pollinations），或複製提示詞到 Google Gemini／ChatGPT／豆包／Pollinations，畫好再從相簿選回來。圖上不放字、不放人臉，經文由 App 排上去。
- **AI 生成配樂**（配樂與錄製分頁）：選曲風、心情、長度，寫好純音樂提示詞，貼到 Suno／Google MusicFX／Stable Audio，下載後從檔案選回來成為配樂。
- **離開去第三方工具再回來，自動接回原位**（經文、畫風、提示詞都還在；系統把 App 收掉重載也一樣）。
- **卡片字體與文字顏色**（文字分頁）：明體／黑體／楷體／圓體；楷體、圓體 App 自帶（霞鶩文楷、粉圓，開源字體，與互動聖經共用，第一次選用才下載約 1–2 MB，畫面有狀態列）；9 色＋自選色，整張原圖的文字也套用。
- **自拍相機打不開時說清楚原因**（權限被拒、被其他 App 佔用、在團契內嵌視窗或 LINE 內嵌瀏覽器），並提供「用瀏覽器開啟並允許相機」與「用手機內建相機錄自拍」兩條退路。
- 沒有 AI 影片（已決定不做）。
- 上傳：index.html、sw.js、version.json（若有）、README.md 一起覆蓋。
