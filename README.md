# 321教會生活（321 Church Life）v1.0.1

321學神院・生活操練課程第四門。52 週 × 5 堂 = 260 堂，繁體／简体／English 三語 PWA。

## 部署（GitHub Pages）
1. 建立 repo：spch321-sudo/321churchlife
2. 把本資料夾「所有檔案」直接上傳到 repo 根目錄（不要放進子資料夾）。
3. Settings → Pages → Branch: main / root。
4. 網址：https://spch321-sudo.github.io/321churchlife/

更新時整批覆蓋上傳即可；App 會自動偵測 version.json 換新版。
